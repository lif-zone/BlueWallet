# BlueWallet-web Tasks
# Porting BlueWallet (React Native) to run on web via lif-kernel at port 4202

## Current Status
App loads and renders the wallets list. Send, SLIP39 and Lightning/Ark flows
were not exercised yet.


## Open Tasks

- Electrum TLS over LIF
  - BlueWallet does not verify TLS (verify==false) because many electrum
    servers are self-signed.
  - client side TLS disabled, since its slow loading. enable once loading
    perf improved.
    - add a button to enable it.
  - TLS for lif_fetch, lif_WebSocket, lif_rpc_websocket.
  - implemented, not yet tested:
    - CA check in tcpip_tls.js
    - Negative TLS security tests (validate fails/rejects when configured to)
- needs still testing
  - Finish re-testing the reworked multisig screens (creating the vault,
    co-signers, export file, multisig send and co-sign)
- React Native -> web porting:
  - web/img_sizes.json is generated: re-run `node web/img_sizes_gen.mjs` when
    images under img/ are added or resized (a missing entry shows at 0x0).
  - web/loc_requires.json is generated: re-run `node web/loc_requires_gen.mjs`
    when loc/index.ts gets a new language (a missing entry shows in English).
  - web/stubs/arkade-os-sdk and web/stubs/arkade-os-boltz-swap are facades
    that list the names BlueWallet imports from the Ark packages: when
    BlueWallet imports a new name, add it there (a missing one fails at start
    with "does not provide an export named ..."). The real versions are
    bw-arkade-* in package.json, with the sdk version pinned for boltz-swap
    in lif.patches.
