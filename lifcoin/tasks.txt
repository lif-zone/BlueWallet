# BlueWallet-lif Tasks
# LIF coin wallets in BlueWallet (lifcoin/, on the anycoin layer)

## Open Tasks

- Add Wallet: the texts of the Lifcoin option ("Lifcoin", "LIF wallet, on
  the LIF network") are not translated: English in every language.
- LIF wallet kinds still missing (Bitcoin has them). Each needs its base
  class to use this.network / this.electrum (anycoin), a LIF variant
  (lif_wallet_class) and its way in:
  - Watch-only: an Lpub inside a descriptor (wpkh([fp/path]Lpub...)) or as
    [fp/path]Lpub is not read: a bare Lpub and an address are. So the
    Taproot watch-only export (a tr(...) descriptor) does not import back.
    ypub / zpub texts are checked on Bitcoin only.
  - Watch-only with an external signer (hardware wallet, PSBT screens): the
    PSBT is made and an HD wallet cosigns it, but the screens were not run
    for LIF. Taproot: cosignPsbt does not finalize (same on Bitcoin).
  - Import of a private key with a script prefix (p2wpkh:WIF): Bitcoin
    only.
  - Multisig vault. Class (multisig-hd-wallet.ts): address network in 3
    places, new bitcoin.Psbt() -> this._newPsbt(), paths m/48'/1842'/0'/2'
    (statics PATH_*, setDerivationPath). Creation: addMultisigStep2.tsx and
    multisig-cosigner.ts name MultisigHDWallet: take the class from a route
    param. Import of a setup file: tell LIF by the coin type of the path.
    Screens: psbtMultisig.tsx (addresses, fiat and "BTC" fee text assume
    Bitcoin), ViewEditMultisigCosigners.tsx (new MultisigHDWallet()).
  - Other seed formats: Electrum seed, SLIP39, aezeed.
- The LIF kinds other than HDlif (HD and single-address: Legacy, P2SH,
  Taproot, single-address SegWit): a real send on the LIF network was not
  done yet (signing was tested with a fake coin).
